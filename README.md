
# Chandra Daya Investasi

Company profile website build with laravel inertia

## 🛠 Requirements
- PHP 8.2 / 8.3 / 8.4
- Composer
- MySQL / MariaDB
- Apache / Nginx
- Laravel Inertia Vue
- Backend Portal Ui (https://muhammadlailil.github.io/portal-docs/portal-ui/card.html)

## ⚙ Installation

Clone Project

```bash
  git clone https://gitlab.com/crocodic_webs/cdi-compro.git
  cd cdi-compro
```

Run Dev

```bash
  yarn dev
```
```bash
  php artisan serve
```

Watch Tailwind
```bash
  .\tailwindcss.exe -i resources/css/input.css -o public/portal-ui/portal-ui.css --watch --minify
```
